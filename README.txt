WHAT'S INCLUDED
- Loading screen lasting at least 4.2 seconds: white photo contours draw from 0–50%, then the original photo fades in from 50–100%. A slim centered progress bar holds the percentage inside.
- Responsive layouts for phones, tablets, desktop and 4K displays.
- Original 4827 × 3218 portrait, with smaller delivery versions for speed.
- Four speaking themes with event enquiry links.
- About COACH DÉA, speaking engagements, moderated conversations, mentorship, podcast, photo gallery and event FAQs.
- Mobile navigation, keyboard focus, motion pause and reduced-motion support.
- Speaking and moderation enquiries stay here; podcast and social links go to their original channels.
- Contact form that prepares an email in the visitor's email app. The visitor sends it; this site does not collect form submissions.

FOR FUTURE EDITS
No installation or dependencies are needed. With Node.js installed:

  npm run build   updates the ready-to-host dist folder
